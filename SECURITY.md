# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose,
overwrite, corrupt, misverify, or delete user media. Send the maintainer a
private report through GitHub Security Advisories for this repository.

Include the affected version or commit, macOS version, storage topology,
reproduction steps using synthetic media, expected behavior, and observed
behavior. Do not attach private footage, credentials, signing material, or
unredacted production manifests.

The project does not currently promise a fixed response SLA, but reports that
can compromise source immutability or produce a false verified result receive
the highest priority.

## Supported versions

Until the first stable release, only the latest commit on `main` is supported.
After 1.0, this document will list supported release lines explicitly.
