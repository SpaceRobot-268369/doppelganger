# Agent Memory

The agent **memory store** — persistent notes agents keep across sessions.

| Folder | Scope |
|--------|-------|
| [`shared/`](shared/) | Shared, **committed** memory — visible to everyone on the repo. |
| [`local/`](local/) | Per-user, **git-ignored** memory — the canonical worktree scope registry and parallel work log, kept in the main checkout only. |
